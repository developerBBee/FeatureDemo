# 5. データ設計

アプリが端末内に保存するデータと、利用者とやり取りするファイルの仕様を定義する。
テーブル定義・アクセス方式の詳細は内部設計で扱う。

## 5.1 保存データ一覧

| データ | 保存先 | 内容 | 書き込み契機 | 保持期間 |
| --- | --- | --- | --- | --- |
| 位置情報の記録 | アプリ専用領域の SQLite データベース `feature_demo.db` | 緯度・経度・取得時刻・日付 | 経路記録中に地点を受信するたび | 無期限(削除機能なし) |
| アプリ設定 | アプリ専用領域の Preferences DataStore `app_settings` | 起動回数・最終起動時刻 | アプリのプロセス起動時 | 無期限 |
| 通知デモのステータス | メモリのみ | 未対応 / 承認済み / 却下 | NT-03 のアクション、SC-09 のボタン | プロセス終了まで |
| 経路記録中フラグ | メモリのみ | 記録中かどうか | 記録の開始・停止 | プロセス終了まで |
| 画面の入力・表示状態 | メモリのみ | SC-05 の入力値、SC-11 の選択画像など | 画面操作時 | 該当画面を閉じるまで |
| HEIC 変換の一時ファイル | アプリのキャッシュ領域 | 変換途中の HEIC データ | HEIC 変換時 | 変換処理の終了時に削除 |

保存データはいずれもアプリ専用領域にあり、他アプリからは参照できない。
OS の設定でアプリの「ストレージを消去」するか、アンインストールすると削除される。

## 5.2 保存データの項目

### 5.2.1 位置情報の記録(テーブル `location_points`)

| 項目 | 型 | 内容 |
| --- | --- | --- |
| `id` | 整数 | 自動採番 |
| `latitude` | 実数 | 緯度(度) |
| `longitude` | 実数 | 経度(度) |
| `timestamp` | 整数 | 位置の取得時刻(エポックミリ秒) |
| `date` | 文字列 | 取得時刻を端末のタイムゾーンで変換した日付(`yyyy-MM-dd`)。SC-10 の日付切り替えの単位 |

SC-10 では `date` 単位で地点をまとめ、日付は新しい順、地点は取得時刻の古い順に表示する。
`date` は記録時点のタイムゾーンで確定するため、後から端末のタイムゾーンを変更しても既存データの日付は変わらない。

### 5.2.2 アプリ設定(DataStore `app_settings`)

| キー | 型 | 内容 | 初期値 |
| --- | --- | --- | --- |
| `launch_count` | 整数 | アプリのプロセス起動回数(Activity の再表示ではなく、プロセス生成ごとに 1 加算) | 0(未保存) |
| `last_launched_at` | 整数 | 最終起動時刻(エポックミリ秒) | 0(未保存) |

書き込みに失敗した場合(ファイル破損・I/O エラー)は記録をスキップし、アプリの起動は継続する。
現時点で値を利用者に表示するのは SC-12(debug ビルド)のみ。

## 5.3 入出力ファイル

### 5.3.1 テキストファイル(SC-05)

| 項目 | 仕様 |
| --- | --- |
| 方向 | 出力 |
| 保存先 | 利用者が OS のファイル保存画面で選択した場所 |
| MIME タイプ | `text/plain` |
| 文字コード | UTF-8 |
| 内容 | 1 行目: タイトル、2 行目以降: 本文 |
| 既存ファイル | 上書き(内容を切り詰めてから書き込む) |

### 5.3.2 画像ファイル(SC-11)

**入力**

| 項目 | 仕様 |
| --- | --- |
| 取得元 | OS の写真選択ツールで利用者が選んだ画像 1 枚 |
| 対応形式 | 端末の OS がデコードできる形式(JPEG / PNG / WebP / GIF / BMP / HEIF など。端末により異なる) |
| サイズ上限 | 長辺が 4096px を超える場合は、4096px 以下になるまで 1/2、1/4… に縮小して読み込む(メモリ不足を避けるため) |

**出力**

| 形式 | 圧縮 | 品質 | 透過(アルファ) | 備考 |
| --- | --- | --- | --- | --- |
| PNG | 可逆 | — | 保持 | |
| JPEG | 非可逆 | 95 | 白背景に合成 | |
| WebP | 非可逆 | 95 | 保持 | |
| GIF | 可逆(LZW) | — | 白背景に合成 | GIF89a 静止画 1 フレーム。256 色の固定パレット(R 3bit / G 3bit / B 2bit)へ減色。最大 65535×65535px |
| BMP | 無圧縮 | — | 白背景に合成 | 24bit。ファイルサイズ上限 2GB |
| HEIC | 非可逆 | 95 | — | Android 9 以上。端末のハードウェアエンコーダーを使用 |

- 出力画像の解像度は入力時(縮小後)の解像度と同じ。
- メタデータ(Exif・位置情報など)は引き継がない。
- 保存先・ファイル名は利用者が OS のファイル保存画面で決定する。変換に失敗した場合は作成された空ファイルを削除する。

## 5.4 バックアップ

| 項目 | 仕様 |
| --- | --- |
| 自動バックアップ | 有効(`allowBackup="true"`) |
| 対象 | 除外ルールを定めていないため、OS の既定どおりアプリ専用領域のデータ(位置情報データベース・DataStore を含む)が対象となる |
| 復元 | 再インストール・機種変更時に OS の仕組みで復元される |

> 位置情報の記録は個人の行動履歴にあたるため、バックアップ対象から除外するかは今後の検討事項とする。
