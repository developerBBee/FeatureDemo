# FeatureDemo 設計書

FeatureDemo(`jp.developer.bbee.featuredemo`)の設計書をまとめたディレクトリ。
利用者・外部システムから見た振る舞いを **外部設計**、実装構造を **内部設計** として分けて管理する。

| 区分 | 内容 | 状態 |
| --- | --- | --- |
| [外部設計](external-design/README.md) | システム概要、画面、通知、権限・外部連携、保存データ | 初版 |
| [内部設計](internal-design/README.md) | アーキテクチャ、モジュール構成、クラス設計、処理フロー | 未着手 |

## 記述ルール

- 設計書はソースコードの現状(`main` ブランチ)を正とし、仕様変更時は同じ PR で設計書も更新する。
- 画面遷移図・シーケンス図は GitHub 上でレンダリングされる Mermaid 記法で書く。
- 画面文言はアプリ内の表示文字列をそのまま記載する(「」で囲む)。
- Android プラットフォームの仕様に依存する記述には、根拠となる公式ドキュメントへのリンクを添える。
